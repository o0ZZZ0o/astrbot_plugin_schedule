# AstrBot 课程表插件 (`astrbot_plugin_schedule`)

> 🤖 **声明**：本插件使用 AI 辅助开发。

这是一个为 **AstrBot** 设计的课程表管理与群互动插件，帮助群组成员方便地管理和查询自己以及群友的课程安排，**深度适配 QQ 官方机器人 (`qq_official`)** 并同时兼容 OneBot (`aiocqhttp`) 等平台。

---

## ✨ 功能特性

- **多种绑定方式**：支持通过发送 `.ics` 日历文件（或下载链接/日历文本）以及 **WakeUp课程表** 分享口令，将个人课表与账号（QQ号 / QQ官方机器人 OpenID）绑定。
- **今日与周课表查询**：支持查看今日剩余课程、今日完整课表、明日课表、本周课表、下周课表，并以精美图片形式展示。
- **群友课程总览**：一条指令查看群里所有已绑定用户的课程状态（进行中 / 下一节 / 空闲），方便约饭、约游戏。
- **本周上课排行**：查看本周群友上课总时长（小时/分钟）和总节数的排行榜，自带金银铜牌与趣味称号。
- **智能状态显示**：自动判断课程是“进行中”还是“下一节”，并实时计算剩余时间或等待时间。
- **高度定制化**：
  - **支持显示 QQ 群昵称，而非 QQ 号或冗长的 OpenID**（支持自动提取群名片、通过 QQ 号拉取昵称或通过 `/设置昵称` 自定义）。
  - **三种独立精心设计的图片渲染样式**：
    1. **个人课表样式**：靛蓝现代卡片时间轴（单日视图）+ 马卡龙配色网格课表（周视图）。
    2. **群友课表总览样式**：青绿社交状态看板，直观区分“上课中”、“待上课”与“当前空闲”。
    3. **本周上课排行榜样式**：暖金荣誉领奖台样式，含金银铜牌、可视化进度条与趣味称号。
  - **能够显示 QQ 头像**：支持 QQ 官方机器人 OpenID 头像 (`thirdqq.qlogo.cn/qqapp/{appid}/{openid}/100`) 与数字 QQ 号高清头像 (`q1.qlogo.cn`) 双通道获取与本地缓存，无网络时自动绘制首字渐变圆形头像。
  - **自动处理时区**：内置完整 RFC 5545 `.ics` 解析与时区转换（默认 `Asia/Shanghai` UTC+8），自动将 UTC 时间转换为本地时间。
  - **每日课表推送与课前提醒**：支持自定义每日定时推送当日课表图片，以及开课前 1~120 分钟自动提醒。

## 📋 命令列表

| 命令 | 功能描述 |
| :--- | :--- |
| `/绑定课表` | 在群聊中发送此命令，然后根据提示发送你的 `.ics` 文件或 WakeUp 分享口令来绑定课表（也支持 `/绑定课表 <口令>` 单步绑定）。 |
| `/查看课表` | 显示你自己今天接下来要上的课程（若今日已无课则附带明日课程预告）。 |
| `/群友在上什么课` | 显示群里所有成员当前正在上或下一节要上的课程。 |
| `/群友明天上什么课` | 显示群里所有成员明天要上的课程。 |
| `/本周上课排行` | 显示本周群友上课时长和节数的排行榜。 |
| `/今日课表` | 输出今日课表图片。 |
| `/明日课表` | 输出明日课表图片。 |
| `/本周课表` | 输出本周课表图片。 |
| `/下周课表` | 输出下周课表图片。 |
| `/设置每日推送` | 配置每日课表自动推送（回复 `"开启 HH:MM"` 如 `"开启 07:00"`，或回复 `"关闭"` 禁用）。 |
| `/设置提醒时间` | 配置开课前提醒的提前时间（回复分钟数，范围 `1-120`，或回复 `"关闭"` 禁用）。 |
| `/查看设置` | 查看当前配置。 |
| `/设置昵称 <群昵称> [QQ号]` | *（QQ官方机器人增强指令）* 自定义显示的群昵称并可选关联真实 QQ 号以同步高清 QQ 头像。 |
| `/解绑课表` | 解除绑定并清除个人课表数据。 |

## 🤖 QQ 官方机器人 (`qq_official`) 适配说明

1. **OpenID 与群聊绑定**：插件自动识别 QQ 官方机器人的 `member_openid`、`user_openid` 与 `group_openid`，无需依赖传统数字 QQ 号即可完成个人课表与群聊关联。
2. **两步交互与单步指令双支持**：在 QQ 官方机器人群聊中需要 `@机器人` 才能触发消息，因此对于 `/绑定课表`、`/设置每日推送`、`/设置提醒时间`，既支持先发送指令再 `@机器人` 回复内容，也支持单条消息直接携带参数（如 `@机器人 /设置每日推送 开启 07:00`、`@机器人 /设置提醒时间 15`、`@机器人 /绑定课表 <WakeUp分享口令>`）。
3. **群昵称与头像显示**：
   - 插件会自动尝试从 `event.bot` 或平台配置中读取 `appid` 并拉取腾讯官方 OpenID 头像。
   - 由于腾讯官方群聊接口默认不推送群成员昵称，用户可发送 `/设置昵称 你的群昵称 你的QQ号`（或在绑定口令末尾附上 `昵称:xxx QQ:123456`），即可在所有课表图片中展示群昵称与高清 QQ 头像。
4. **主动推送权限**：使用 `/设置每日推送` 和 `/设置提醒时间` 时，请确保在手机 QQ 群机器人设置中开启了“允许机器人主动在群内发言”，且机器人具备主动消息配额。
