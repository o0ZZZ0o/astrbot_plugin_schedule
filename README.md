# AstrBot 课程表插件 (`astrbot_plugin_schedule`)

> 🤖 **声明**：本插件使用 AI 辅助开发。

这是一个为 **AstrBot** 设计的课程表管理与群互动插件（当前版本：`v1.4.1`），帮助群组成员方便地管理和查询自己以及群友的课程安排，**深度适配 QQ 官方机器人 (`qq_official`)** 并同时兼容 OneBot (`aiocqhttp`) 等平台。

---

## ✨ 功能特性

- **多种绑定方式**：支持通过发送 `.ics` 日历文件（或下载链接/日历文本）以及 **WakeUp课程表** 分享口令，将个人课表与账号（QQ号 / QQ官方机器人 OpenID）绑定。
- **动态时间轴与个人周数自适应**：
  - 自动根据每个人的课表文件（`.ics` 或 WakeUp）动态推算**每节课的开始时间、结束时间、单节课程时长、课间休息间隙及每日总节数**，并在周课表左侧时间轴与大课间分割线上精准呈现。
  - 自动识别并独立计算**每个人的学期起始周、学期总周数及每门课的上课周数范围**（支持全周、单双周、非连续周如 `1-8,10-16周`），并支持 `/设置当前周`、`/设置总周数` 随时微调。
- **今日与周课表查询（完整支持周六、周日课程）**：支持查看今日剩余课程、今日完整课表、明日课表、本周课表、下周课表，并以高清自适应图片展示，完整显示周一至周日全周排课，长课程名与长教室名自动换行绝不截断。
- **群友课程总览**：一条指令查看群里所有已绑定用户的课程状态（进行中 / 下一节 / 空闲），方便约饭、约游戏。
- **本周与下周上课排行**：查看群友上课总时长（小时/分钟）、总节数与早八次数排行榜，自带金银铜牌与趣味称号。
- **自动课前推送提醒（支持 QQ 官方机器人 `@某人`）**：
  - 独立指令控制课前提醒开关（`/课前提醒`）与开课前提醒时长（`/设置提醒时间`，范围 `1-120` 分钟）。
  - 到达提醒时间时自动在群内 **`@对应成员`**（适配 QQ 官方机器人 `<@member_openid>` 原生艾特语法与 OneBot `At` 组件）。
- **早八前夜自动提醒（支持 QQ 官方机器人 `@某人`）**：
  - 支持自定义**在有早八那一天的前一天几点进行提醒**（`/设置早八提醒时间`，如前一天晚上 `21:30`）。
  - 支持自定义**什么时候开始的课程算作早八**（`/设置早八时间`，如 `08:00` 或 `08:30`）。
  - 支持通过 `/早八提醒` 随时开启或关闭，触发时自动 **`@对应成员`** 提醒定闹钟早睡。
- **周日自动推送下周上课情况图片**：
  - 每逢周日指定时间点，自动统计全群成员下周课程并生成仿照本周上课排行样式的 **《下周群友上课情况排行》** 黑金荣耀榜图片推送到群内。
  - 支持通过 `/周日推送` 与 `/设置周日推送时间` 控制开关及设定推送时间点，也支持平时随时发送 `/下周上课排行` 查看。
- **高度定制化与 Debian Linux 深度优化**：
  - 支持显示 QQ 群昵称而非 QQ 号或冗长的 OpenID，支持显示丝滑抗锯齿圆形 QQ 头像。
  - 内置双字重中文字体与 Debian Linux 字形校验机制，彻底杜绝 Linux 服务器下的 `□□□` 中文乱码方框。

## 📋 命令列表

| 命令 | 功能描述 |
| :--- | :--- |
| `/绑定课表` | 在群聊中发送此命令，然后根据提示发送你的 `.ics` 文件或 WakeUp 分享口令来绑定课表（也支持 `/绑定课表 <口令>` 单步绑定）。 |
| `/查看课表` | 显示你自己今天接下来要上的课程（若今日已下课则展示今日回顾并附带明日课程预览）。 |
| `/群友在上什么课` | 显示群里所有成员当前正在上或下一节要上的课程。 |
| `/群友明天上什么课` | 显示群里所有成员明天要上的课程。 |
| `/本周上课排行` | 显示本周群友上课时长和节数的排行榜图片。 |
| `/下周上课排行` | *（别名 `/下周上课情况`）* 显示下周群友上课时长和节数的排行榜图片。 |
| `/今日课表` | 输出今日课表图片。 |
| `/明日课表` | 输出明日课表图片。 |
| `/本周课表` | 输出本周课表图片（完整包含周一至周日）。 |
| `/下周课表` | 输出下周课表图片（完整包含周一至周日）。 |
| `/设置每日推送` | 配置每日课表自动推送（回复 `"开启 HH:MM"` 如 `"开启 07:00"`，或回复 `"关闭"` 禁用）。 |
| `/课前提醒` | *（别名 `/设置课前提醒`）* 单独控制开课前自动推送并 `@你` 提醒的开关（回复 `"开启"` 或 `"关闭"`）。 |
| `/设置提醒时间` | 单独配置开课前提醒的提前分钟数（回复分钟数，范围 `1-120`）。 |
| `/早八提醒` | *（别名 `/设置早八提醒`）* 控制早八前一天自动 `@你` 提醒的开关（回复 `"开启"` 或 `"关闭"`）。 |
| `/设置早八提醒时间` | 设置在有早八那一天的前一天几点进行提醒（如回复 `"21:30"` 或 `"22:00"`）。 |
| `/设置早八时间` | *（别名 `/设置早八判定时间`）* 设置几点及之前开始的课程算作早八（如回复 `"08:00"` 或 `"08:30"`）。 |
| `/周日推送` | *（别名 `/设置周日推送`）* 控制周日自动推送下周上课情况排行图片的开关（回复 `"开启 20:00"` 或 `"关闭"`）。 |
| `/设置周日推送时间` | 单独设置周日推送下周上课情况的时间点（如回复 `"20:00"`）。 |
| `/设置当前周 <周数> [总周数]` | *（别名 `/设置周数`）* 动态调整个人课表当前所在周数及可选的学期总周数（如 `/设置当前周 11 18`）。 |
| `/设置总周数 <周数>` | 单独修改个人课表的学期总周数（如 `/设置总周数 18`）。 |
| `/查看设置` | 查看当前个人课表、每日推送、课前提醒、早八提醒及周日推送配置。 |
| `/设置昵称 <群昵称> [QQ号]` | *（QQ官方机器人增强指令）* 自定义显示的群昵称并可选关联真实 QQ 号以同步高清 QQ 头像。 |
| `/解绑课表` | 解除绑定并清除个人课表数据。 |
